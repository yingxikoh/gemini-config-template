# Environment Setup Protocol

This repository serves as your personal version-controlled configuration and preferences repository for the Gemini CLI environment.

## 1. Hierarchy of Context
- **Global Context (`~/.gemini/GEMINI.md`)**: Always-on rules that follow you across all workspaces.
- **Repository Context (`./GEMINI.md`)**: Workspace-specific instructions active when working inside a particular project.

## 2. Personal Work History & Memory
Keep your durable preferences, project milestones, and notes organized inside the `memory/` folder.
